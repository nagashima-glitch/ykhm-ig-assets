# AI の頼み分けルール

「どの仕事を、どの AI に頼むか」を決めた紙です。
むずかしい言葉は使いません。

---

## 1. AI を 3 人の相手だと思う

| 相手 | 正体 | 得意なこと | お金 |
|---|---|---|---|
| 相談相手 | ChatGPT の無料版（Claude の無料チャットでも可） | 「何を作るか」を一緒に考える | タダ |
| パート事務さん | Codex の軽い設定 | やることが決まっている単純作業 | 安い |
| ベテラン職人 | Claude Code / Codex の賢い設定 | 判断や設計が要る難しい仕事 | 高い |

**考えるのはタダの相談相手。作るのは職人。これだけ覚えれば足りる。**

### なぜ分けるのか

AI の料金は「読んだ文字数 ＋ 書いた文字数」で決まる。
ぼんやりした状態でベテラン職人に頼むと、職人はまず資料を端から端まで読み直す。
**実はここが一番お金がかかる。**

逆に「このファイルの、この文章を、こう直して」と決まっていれば、
読む量が少なくて済むので安く終わる。だから先に無料の相談相手で固める。

---

## 2. どれに頼むかの一覧

| やりたいこと | 頼む相手 | なぜ |
|---|---|---|
| インスタの企画・文章を考える | 相談相手（無料） | ファイルを触らない話なので無料で十分 |
| インスタの画像・リールを上げて確認ページを作る | Claude Code | 今のやり方のまま。すでに手順ができている |
| HP の文字・色・写真をちょっと直す | パート事務さん | 直す場所が分かっているなら安い方で足りる |
| HP を作り替える・ページ構成を変える | ベテラン職人 | 設計の判断が要る。ここはケチらない |
| 名前の一括変更・同じ作業のくり返し | パート事務さん | 完全に単純作業 |
| 原因の分からない表示崩れ・不具合 | ベテラン職人 | 安い方で何度もやり直す方が結局高くつく |
| GitHub のやりとり（PR・エラー対応） | Claude Code | GitHub とつながる仕組みが最初から入っている |

---

## 3. 安く済ませるための 5 つのコツ

1. **1 つの用事につき 1 回の会話で終わらせる。**
   会話が長くなるほど、AI は毎回それまでの話を読み直すのでお金がかかる。
2. **探させない。**
   「どこかにあるはず」ではなく「`posts/2026-09-13/index.html` の中」と場所を書いて渡す。
3. **相談は無料の相手と。**
   「どう作るか」で迷っている段階を、お金のかかる相手とやらない。
4. **お願いの書き方をそろえる（→ 4 番）。**
   「できたかどうかの見分け方」まで書いてあると一発で終わる。
5. **大きいファイルを読ませない。**
   `posts/` のフォルダは 40MB 超。画像そのものを見てもらう用事がなければ触らせない。

---

## 4. お願いの書き方（これを無料の相談相手と作る）

```
【何のため】ひとことで
【どこを】フォルダやファイルの場所
【やってほしいこと】箇条書き。ひとつずつ「できたらこうなる」まで書く
【やらないでほしいこと】触ってほしくないところ
【確認のしかた】どこを見れば成功と分かるか
```

これをそのままコピーして渡せば、安い相手でも高い相手でも同じ結果になる。

## 5. 「難しい仕事のときは賢い AI に自動で」の設定

**先にはっきり書いておくと、Codex に「仕事の中身を見て勝手に賢いモデルへ切り替える」機能はない。**
そこで、近いことを 3 つの仕掛けでやる。

### (a) 設定を 3 つ用意しておく
`docs/codex-config.example.toml` の中身を `~/.codex/config.toml` に貼り付ける。
以後、起動するときに選ぶだけになる。

- `codex --profile deep` … 賢い（HP の作り替え・原因不明の不具合）
- `codex --profile fast` … 軽い（文字直し・単純作業）
- `codex --profile review` … 読むだけ（書き換えさせない）

### (b) フォルダで自動的に選ばせる
下の 8 行を `~/.zshrc`（Mac の標準。bash なら `~/.bashrc`）の一番下に貼る。
HP のフォルダで作業を始めたら勝手に「賢い」、資産のフォルダなら「軽い」になる。

```sh
codex() {
  local profile=fast
  case "$PWD" in
    *ykhm-hp*|*homepage*|*site*) profile=deep ;;   # HP の作り替えは常に賢い方
    *ykhm-ig-assets*|*signage*)  profile=fast ;;
  esac
  command codex --profile "$profile" "$@"
}
```

自分で `codex --profile deep` と打てば、そちらが優先される。

### (c) AI 向けの指示書を置いておく
各フォルダの `AGENTS.md` に「こういう時は賢い設定に切り替えてから始めること」と書いてある。
AI は作業を始める前にこれを読むので、実質は AI が自分で判断して切り替えてくれる。

会話の途中で変えたいときは `/model`・`/reasoning` と打つ。

---

## 6. 「Astra に頼む」のはアリか

アリ。ただし使い分ける。

- **Astra（Codex の賢い設定）** … HP の作り替え、原因不明の不具合。ChatGPT Plus の Codex から使える
- **Claude Code** … GitHub のやりとりと、インスタ投稿のような今できあがっている手順
- **同じ仕事を両方に頼まない。** 迷ったら片方に作らせて、出てきたものをもう片方に見てもらう方が安い

> モデルの名前と値段は変わる。`codex` の中で `/model` と打って、実際にある名前に直してから使うこと。
